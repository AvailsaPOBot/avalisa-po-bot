Why an end point matters more with a bot

When you trade by hand, tiredness is your natural off switch. When the trades place themselves, that switch disappears. The usual failure is not one bad trade but a session that keeps extending because each next trade feels like “one more”. An end point written down before the first trade replaces the impulse with a rule.

What the bot controls, and what it does not

  • Martingale mode raises the stake after a loss by the multiplier you choose: 2x, 2.2x, 2.4x, 2.6x, 2.8x or 3x.
  • There is no separate stop-loss or daily-loss-limit setting. Limiting Martingale Steps is the real way to cap a losing streak. Steps can be a number or Infinite — and Infinite is exactly what an end point rules out.
  • If the next stake would exceed your balance, the bot pauses. That is a safety floor, not a plan.

The bot runs the system you chose; it does not judge when that system is going badly for you. That judgement is yours, made in advance. Sizing the money behind it is covered in bankroll rules for automation.

Write your end point before you open the platform

  1. Cap the cycle in trades. Choose a finite Martingale Steps value and know what it allows: Steps = N permits N + 1 trades in a losing cycle (the first trade plus N recovery trades), then the stake resets to the start amount. At 2x, Steps 3 means up to 4 trades and a worst-case cycle cost of 15× the base stake.
  2. Pick a multiplier you can explain. A lower multiplier (2x rather than 3x) grows each recovery stake more slowly. Pick it first, then choose Steps so the largest stake in the cycle fits the money set aside for this session. The Martingale calculator shows every stake.
  3. Set a money end point. Decide the largest losing session you will accept and write the number down. With no built-in daily-loss limit, you are the daily-loss limit. When the balance has moved that far, stop.
  4. Set a clock cap. A start time and an end time, or a maximum number of sessions a day. Sessions that drift past the planned window are where impulsive changes happen.
  5. Set a walk-away trigger. “Two losing cycles in a row” is a legitimate trigger. So is noticing that you cannot stop checking the screen.
  6. Use the trade filters. Timeframe and Minimum payout % decide which trades are taken. At payout p, break-even win rate = 1 / (1 + p), about 52.1% at 92%; lower payouts push that line higher.
  7. Put it on one line each — Steps, multiplier, money cap, clock cap, walk-away trigger — somewhere you will see it.

Running the session with the rules in force

  • Keep the Pocket Option tab visible. A background or minimised tab can delay trade-result detection, so a session can run past its end point without you noticing.
  • Do not change settings mid-session. Editing Steps or the multiplier while a cycle is open is how an end point slides. Stop, write a new plan, start a new session.
  • Stopping at your cap is the plan working, even when the session lost.
  • Review afterwards, not during. Compare what happened with what you wrote — a trading journal makes this easy.

Risk statement

Binary options are high risk, and you can lose your entire deposit. In our large-sample measurements no setting has beaten break-even, and no combination of stopping rules changes that. Frequently asked questions

How many losing trades should I allow in one session?

There is no universal number. Ask instead: what does the whole cycle cost if every trade in it loses? Steps = N is N + 1 trades, so at 2x, Steps 3 is 4 trades and 15× the base stake. Choose Steps so that number is a loss you can accept calmly, then check it on demo.

Does the bot have a daily loss limit?

No. There is no separate stop-loss or daily-loss-limit setting. Limiting Martingale Steps caps a losing streak, and the bot pauses if the next stake would exceed your balance. Any per-session or per-day limit is one you set and enforce yourself.

Should I watch the whole time?

No, but do not hide the tab. Keep it visible so results are detected on time, and check at the end points you wrote down.

Can I practise my stopping rules without real money?

Yes. The extension works on Pocket Option demo accounts the same way as on real ones, and demo is where these rules belong first.
